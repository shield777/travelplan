# Firebase 설정 안내 (PC에서 한 번만)

여행일정 앱을 가족끼리 **실시간으로 함께 쓰기** 위한 준비예요. PC 크롬이나 엣지에서 하시면 편해요. 20~30분 걸려요.

> Firebase 화면은 가끔 이름이 조금씩 바뀌어요. 아래와 똑같은 글자가 없으면 **비슷한 이름**을 누르시면 돼요. 화면이 많이 다르면 캡처해서 보여 주세요.

---

## 1. 프로젝트 만들기

1. https://console.firebase.google.com 에 접속해서 **본인 구글 계정**으로 로그인해요.
2. **프로젝트 만들기**(Create a project 또는 "Firebase 프로젝트 시작하기")를 눌러요.
3. 프로젝트 이름: `travelplan` → 계속
4. **Google 애널리틱스**는 **사용 안 함**으로 끄고 → **프로젝트 만들기**
5. Gemini(AI 도우미) 관련 질문이 나오면 꺼도 돼요.
6. 1분쯤 뒤 "새 프로젝트가 준비되었습니다" → **계속**

## 2. 웹 앱 등록 → 설정값 받기 ⭐ (저에게 보내 주실 것)

1. 프로젝트 첫 화면(프로젝트 개요)에서 **웹 아이콘 `</>`** 를 눌러요.
2. 앱 닉네임: `여행일정`
3. **"이 앱의 Firebase 호스팅도 설정합니다"는 체크하지 마세요.** (앱은 이미 GitHub에 있어요)
4. **앱 등록**을 누르면 아래처럼 생긴 코드가 나와요.

   ```js
   const firebaseConfig = {
     apiKey: "AIza....",
     authDomain: "travelplan-xxxxx.firebaseapp.com",
     projectId: "travelplan-xxxxx",
     storageBucket: "travelplan-xxxxx.firebasestorage.app",
     messagingSenderId: "1234567890",
     appId: "1:1234567890:web:abcdef..."
   };
   ```

5. 이 **`firebaseConfig` 부분 6줄을 복사해서 저에게 보내 주세요.**
   - 이건 비밀번호가 아니에요. "어느 프로젝트인지" 알려 주는 주소 같은 값이라 공개 저장소에 올라가도 괜찮아요. 실제 보호는 5번의 **보안 규칙**이 해요.
6. **콘솔로 이동**을 눌러요.

## 3. 구글 로그인 켜기

1. 왼쪽 메뉴 **빌드(Build) → Authentication** → **시작하기**
2. **로그인 방법(Sign-in method)** 탭 → **Google** 선택
3. **사용 설정(Enable)** 을 켜고, **프로젝트 지원 이메일**에 본인 이메일을 고른 뒤 **저장**
4. 같은 Authentication 화면의 **설정(Settings)** 탭 → **승인된 도메인(Authorized domains)** → **도메인 추가**
   - `shield777.github.io` 를 입력하고 **추가**
   - 이걸 빠뜨리면 앱에서 로그인이 안 돼요.

## 4. 데이터베이스(Firestore) 만들기

1. 왼쪽 메뉴 **빌드(Build) → Firestore Database** → **데이터베이스 만들기**
2. 버전(Edition)을 물으면 **Standard**
3. 위치(Location): **asia-northeast3 (Seoul)**
   - ⚠️ 위치는 나중에 바꿀 수 없어요.
4. 보안 규칙 시작 모드: **프로덕션 모드(Production mode)** → **만들기**

## 5. 보안 규칙 넣기

1. Firestore Database 화면 위쪽 **규칙(Rules)** 탭
2. 안에 있는 내용을 **모두 지우고**, 이 저장소의 [`firestore.rules`](../firestore.rules) 파일 내용을 **통째로 복사해서 붙여넣기**
3. **게시(Publish)** 를 눌러요.

규칙 요약:
- 구글로 로그인한 사람 중 **가족으로 등록된 이메일만** 그 가족의 여행을 볼 수 있어요.
- 여행을 **고치거나 지우는 건 만든 사람(본인)과, 본인이 "수정 가능" 권한을 준 가족만** 할 수 있어요.
- 공유 링크로 보는 사람용 사본(`public`)은 로그인 없이 읽을 수 있어요(번호를 아는 한 건씩만, 예약번호 제외).
- 규칙(firestore.rules)이 바뀌면 Firebase 콘솔 → Firestore → **규칙** 탭에 새 내용을 붙여넣고 **게시**를 다시 눌러야 해요.
- 가족 구성원 추가·삭제는 **처음 가족을 만든 사람(본인)만** 할 수 있어요.
- 가족 이메일은 Firestore 안에만 저장돼서 GitHub(공개 저장소)에는 드러나지 않아요.

## 6. 요금제

- **Spark(무료)** 그대로 두세요. **결제 정보는 넣지 마세요.**
- 무료 한도: 하루 읽기 5만 번, 쓰기 2만 번. 가족 여행 앱은 하루 수백 번 수준이에요.
- 한도를 넘어도 요금은 나오지 않고, 그달에 잠시 멈출 뿐이에요.
