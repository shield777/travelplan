Claude API 키

번역은 Anthropic의 Claude가 해요. 키는 이 기기에만 저장되고, 번역할 때 Anthropic 서버로만 보내져요.

키 받는 방법
  1. console.anthropic.com 에 가입해요. Claude 채팅 구독과 따로 운영되는 개발자용 사이트예요.
  2. Billing(결제) 메뉴에서 카드를 등록하고 크레딧을 충전해요. 최소 5달러예요.
  3. Limits(한도) 메뉴에서 월 사용 한도를 5달러 정도로 정해 두면 키가 새도 큰 돈이 나가지 않아요.
  4. API Keys 메뉴에서 Create Key를 누르고, 나온 키를 복사해 위 칸에 붙여 넣어요.
  5. 가족 휴대폰에도 같은 키를 넣으면 같이 쓸 수 있어요. 요금은 한 계정으로 합쳐서 나가요.

번역 모델

금액은 번역 1번당 대략적인 값이에요. 대화가 길어지면 조금 늘어나요.
