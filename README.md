# 여행일정 (travelplan)

아이폰·아이패드(안드로이드·PC도 가능)에서 쓰는 여행 일정 웹앱이에요. 설치나 서버 없이 브라우저에서 돌아가고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 기능

| 요청 | 구현 내용 |
| --- | --- |
| 1. 일별 흐름 | 일차별 세로 타임라인. 일차 제목 옆 ▲▼로 그날 일정을 앞뒤 날과 통째로 바꿀 수 있어요(항공편·숙소는 예약 날짜 그대로). 같은 날 안에서는 시간 아래 동그라미로 일정을 체크하면 아래에 [위로·아래로] 막대가 떠서 순서를 바꿔요(시간도 서로 바뀌어요). 일정에 장소·주소를 넣으면 국내 여행은 **네이버지도 앱**, 해외 여행은 **구글맵 앱**으로 바로 열려요(여행의 나라 기준). 휴대폰 종류에 맞게 열려요: 아이폰·아이패드는 앱 전용 주소(앱이 깔려 있어야 열려요), 안드로이드는 앱으로 열고 앱이 없으면 플레이스토어로, PC는 웹 지도로(티맵은 웹이 없어서 PC에서는 버튼이 안 보여요). 항공편은 시간 순서에 맞춰 자동으로 끼워 넣어져요. 일차마다 제목(예: 교토 당일치기)을 붙일 수 있어요. 투어·식당처럼 예약이 필요한 일정은 예약(예약완료·예약필요), 그 아래 결제(결제·미결제)와 결제 수단(현금·카드·GLN)을 골라 두면 카드에 [예약완료] [결제 · 카드]처럼 표시돼요. 여행 중에는 오늘 일차의 진행 중인 일정부터 보여 줘요. |
| 2. 항공·공항 정보 | 편명(KE723)과 공항 이름(인천, 간사이, 나트랑처럼 이름이나 도시로 검색)만 넣으면 항공사, 공항 이름(한글·영문), 터미널(추정), 시차, 비행시간, 공항 팁, 주차장(국내 공항은 카카오맵·티맵·네이버 앱 버튼, 인천공항은 P1~P5·예약주차장까지 터미널별로), 공식 사이트, 실시간 게이트·지연 확인 링크가 나와요. 한 번 넣은 편명은 이 기기에 기억돼서 다음에 편명만 넣으면 공항·시간이 자동으로 채워져요(노선을 모르면 입력창의 구글·네이버 찾기 버튼). 카드에는 출발 터미널 · 발권 카운터 · 예약번호가 한 줄로 보여요. 발권(체크인) 카운터는 항공편 카드의 **실시간 확인** 버튼(구글·네이버 편명 검색, 출발 공항 운항정보, Flightradar24)으로 찾아서 입력해요. 공항 70곳 정도(국내 7 + 일본·동남아·미주·유럽 등)가 들어 있어요. |
| 숙박 | **숙박** 탭에서 숙소 이름·주소·체크인/아웃·예약번호를 넣으면 숙소 위치가 **구글맵**으로 카드 안에 보여요. 구글맵 앱 버튼(국내 숙소는 네이버지도·카카오맵도)이 있고, 체크인·체크아웃은 일정 타임라인에 자동으로 들어가요. |
| 3. 여행 전 할 일 | 체크박스, 완료율 막대. 할 일은 사전준비·기타로 나눠 보여요. 추가할 때 비용(원)도 같이 넣으면 경비 탭에 들어가요(고칠 때는 할 일을 눌러 수정 창에서). |
| 4. PDF 내보내기 | 항공편·공항 정보·일정·체크리스트 중에서 골라 A4 PDF로 만들어요. 아이폰에서는 공유 시트가 열려서 “파일에 저장”이나 카카오톡 전송을 할 수 있어요. “인쇄” 버튼으로 시스템 인쇄(PDF 저장)도 돼요. |
| 5. 여행별 구분 | 여행마다 **연도 · 나라 · 여행지**를 따로 입력하고(예: `2026 · 일본 · 오사카`), 목록은 연도별로 묶여요. D-day도 함께 보여요. |
| 6. 멤버와 공유 | 여행 화면의 **공유** 버튼으로 링크를 만들어 카톡·메시지로 보내요. 받은 사람은 앱 설치 없이 링크만 눌러 일정을 보고, **내 앱에 저장**도 할 수 있어요. |
| 7. 경비 | 일정·항공편·숙소를 추가·수정할 때의 **비용** 칸(일정은 현지 통화도 가능), 준비 항목을 추가할 때의 비용, **경비** 탭에서 쓴 돈을 현지 통화로 넣으면 원화로 바꿔 합계를 보여 줘요. 총액·하루 평균·1인당, 항목별(항공·숙소·교통·식사·관광·투어·쇼핑·사전준비·기타, 준비 탭 비용은 그 항목의 분류대로), 날짜별·일정별 합계가 나와요. |

## 웹앱으로 배포하기 (GitHub Pages, 무료)

> 아이폰에서는 GitHub 설정 화면이 잘 안 보여요. **아이패드 Safari**나 컴퓨터로 github.com에 로그인해서 하는 게 편해요.

1. **저장소 공개로 바꾸기**: 저장소 → **Settings** → 맨 아래 **Danger Zone** → **Change visibility** → **Make public**
   - 공개되는 건 앱 코드뿐이에요. 여행 일정·경비는 각자 기기에만 저장돼서 저장소에 올라가지 않아요.
2. **Pages 켜기**: **Settings** → 왼쪽 메뉴 **Pages** → Source: **Deploy from a branch** → Branch에서 앱 코드가 있는 브랜치와 **/ (root)** 선택 → **Save**
3. 1~2분 뒤 같은 화면 위쪽에 주소가 나와요: `https://shield777.github.io/travelplan/`
4. 아이폰 Safari로 그 주소를 열고 **공유 → 홈 화면에 추가**를 누르면 앱 아이콘이 생겨요.
5. 가족도 같은 주소를 열어 홈 화면에 추가하면 돼요. 일정은 **공유** 버튼으로 보내세요.

앱을 고쳐서 같은 브랜치에 올리면 1~2분 뒤 자동으로 새 버전이 돼요. (홈 화면 앱은 한 번 껐다 켜면 반영돼요.)

## 멤버와 함께 쓰기 (구글 로그인 · 실시간 동기화)

- 첫 화면 위쪽 **👥 버튼** → 구글로 로그인 → **그룹 만들기** → 멤버 구글 이메일 추가
- 여행 화면 **공유 → 올리고 공유하기**를 누르면 그 여행이 그룹에 올라가요. 멤버 모두 실시간으로 볼 수 있고, 아이폰·아이패드도 자동으로 맞춰져요.
- **고치기·지우기는 그룹을 만든 사람과 "수정 가능" 권한을 받은 멤버만** 할 수 있어요. 나머지 멤버는 보기만 해요. 권한은 👥 멤버 창에서 이름 옆 버튼(보기만 ↔ 수정 가능)으로 바꿔요. 서버 규칙(firestore.rules)으로도 막혀 있어요.
- 공유 링크(`https://shield777.github.io/travelplan/#t=…`)는 **누구나 볼 수 있고**(예약번호·경비 제외), 고치기는 권한을 받은 멤버만 로그인해서 할 수 있어요.
- 인터넷이 없을 때 고친 내용은 기기에 남아 있다가 연결되면 올라가요. 같은 여행을 두 사람이 **동시에** 고치면 나중에 저장한 쪽이 남아요.
- Firebase 처음 설정은 [docs/FIREBASE_SETUP.md](docs/FIREBASE_SETUP.md), 보안 규칙은 [firestore.rules](firestore.rules)

## 경비와 환율

- 경비는 **현지 통화 그대로** 넣어요(예: 25,800엔). 원화는 여행에 저장된 환율로 계산돼요.
- **환율 정하는 방법은 세 가지예요.**
  1. **최신 환율 불러오기**: 무료 환율 서비스(open.er-api.com, 안 되면 currency-api)에서 그날의 시장 환율을 가져와요. 환율이 없는 통화로 경비를 저장하면 자동으로 한 번 시도해요.
  2. **직접 입력**: 환전 영수증이나 트래블카드 앱의 환율을 넣어요. 실제와 가장 가까워요. 엔·동·루피아는 은행처럼 100단위 기준이에요(100엔 = 905원).
  3. **실제 원화 결제액**: 카드 명세서 금액을 경비마다 넣으면 환율보다 이 금액이 우선이에요.
- 환율은 저절로 바뀌지 않아요. 여행 중 쓴 돈은 그때 환율로 고정돼야 해서, 바꾸고 싶을 때만 버튼을 누르세요.
- 시장 환율은 카드 청구액과 수수료만큼(보통 1~2%) 차이가 날 수 있어요.

## 일정 공유하기 (링크 하나)

1. 여행 화면 위쪽 **공유** → (처음 한 번) **올리고 공유하기**로 그룹에 올려요.
2. **카톡으로 보내기**나 **복사**로 `https://shield777.github.io/travelplan/#t=그룹번호.여행번호` 링크를 보내요.
3. 링크를 받은 사람은 **누구나 로그인 없이 볼 수 있어요.** 일정을 바꾸면 **자동으로 반영**돼서 링크를 다시 보낼 필요가 없어요.
4. **고치기**는 그룹을 만든 사람과 **수정 권한을 받은 멤버**만, 화면 위쪽 **멤버 로그인**을 하면 할 수 있어요.

알아 둘 점:

- 링크로 보는 사람에게는 **항공 예약번호·숙소 예약번호·경비가 보이지 않아요.** 이 항목은 보기용 사본에 아예 들어가지 않아요.
- 링크를 아는 사람은 누구나 볼 수 있으니 필요한 사람에게만 보내세요. 공유를 멈추려면 공유 창의 **공유 끄기**를 누르세요.
- 예전에 받은 긴 보기 전용 링크(`#s=`)도 그대로 열려요.
- iOS 16.4 이상에서 열려요.

## 꼭 알아야 할 한계

- **그룹에 올리지 않은 여행은 그 기기에만 저장돼요.** 다른 기기와 맞추려면 공유(그룹에 올리기)를 쓰거나, **불러오기 → 백업 파일 만들기**로 옮기세요.
- **Safari 데이터를 지우면 여행도 지워져요.** 여행 전에 백업 파일을 한 번 만들어 두세요.
- **탑승 게이트·좌석은 입력하지 않아요.** 게이트는 출발 당일 정해지고 자주 바뀌어서, 항공편 카드의 “실시간 확인” 링크(구글·Flightradar24)나 항공사 앱으로 확인하세요. 예전에 넣어 둔 게이트·좌석 값은 지우지 않고 저장만 해 둬요.
- **터미널은 “추정”이에요.** 인천공항은 항공사 기준(대한항공·진에어·아시아나·에어서울·에어부산·델타·에어프랑스·KLM → T2, 2026.1.14 아시아나 이전 반영)으로 추정해요. 확인된 항공사만 넣어서, 그 밖의 T2 항공사는 T1로 잘못 나올 수 있어요. 항공권에 적힌 터미널을 직접 입력하면 그 값이 우선이에요.
- **주차 요금·잔여 면수는 넣지 않았어요.** 자주 바뀌는 정보라 공식 사이트 링크로 대신해요.

## 파일 구성

```
index.html              화면 뼈대
css/style.css           디자인 (밝은/어두운 모드 자동)
js/airports.js          공항·항공사 데이터 ← 공항 추가·수정은 여기서
js/app.js               앱 동작
vendor/html2pdf…js      PDF 생성 라이브러리 (오프라인에서도 PDF가 되도록 함께 넣음)
sw.js, manifest…        홈 화면 앱·오프라인 지원
```

### 공항 추가하는 법

`js/airports.js`의 목록에 한 줄을 복사해서 고치면 돼요. 파이썬이나 빌드 도구는 필요 없어요.

```js
{ code: 'OKA', ko: '나하공항', en: 'Naha Airport', city: '오키나와', country: '일본', tz: 'Asia/Tokyo', terminals: [], notes: ['메모'] },
```

`tz`는 시차 계산에 쓰는 시간대 이름이에요(예: `Asia/Tokyo`, `Europe/Paris`).
